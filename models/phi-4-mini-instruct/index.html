Setup and common questions

Which Phi model is this?

Use Microsoft’s Phi-4-mini-instruct, a 3.8B-parameter text model under MIT. Phi-4-mini-reasoning and Phi-4-multimodal are different checkpoints; these memory estimates do not cover them.

Which file should I use?

LM Studio Community provides a matching Q4_K_M GGUF conversion of Microsoft’s checkpoint, about 2.49 GB before cache and buffers. The Finder uses a conservative 3.80 GB weight input. The Q5 table is a planning profile, not a file in that repository. Keep the correct chat template.

Why start at 4K when the model supports 128K?

The model’s 128K limit describes supported sequence length, not free memory. More context increases the cache. Start small, check runtime memory and compare answers on your task before increasing it. A small model can still give incorrect facts.

How are these recommendations chosen?

We compare dedicated GPU memory tiers using the main Finder’s memory calculation at the stated quantisation and context. These tiers describe memory fit, not speed or output quality.

Allocations are shown in GiB; weight inputs use decimal GB. Nominal hardware capacities are treated as GiB tiers. We include a 0.9 decimal-GB runtime allowance and a 3% reserve (0.15–1.5 GiB). Cache settings and runtime buffers can change the fit. See the calculation assumptions.
