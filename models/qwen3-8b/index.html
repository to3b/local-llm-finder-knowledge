Setup and common questions

Which checkpoint should I download?

Use Qwen/Qwen3-8B and the publisher’s GGUF files. This checkpoint supports thinking and non-thinking modes. Keep that mode fixed when comparing results; thinking output uses tokens and time before the final answer.

Can I use its full context window?

Qwen lists 32,768 native tokens and up to 131,072 with YaRN. Extended context needs explicit runtime support and more memory. The Finder’s 64K planning limit does not verify YaRN support. See context length.

What if it loads but runs out of memory?

Close other GPU workloads and reduce context. If needed, use a smaller file or partial CPU offload. For Macs or CPU-only setups, select the appropriate mode in the Finder; installed RAM is not dedicated VRAM.

How are these recommendations chosen?

We compare dedicated GPU memory tiers using the main Finder’s memory calculation at the stated quantisation and context. These tiers describe memory fit, not speed or output quality.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
