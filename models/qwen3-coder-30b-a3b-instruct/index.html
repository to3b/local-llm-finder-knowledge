Setup and common questions

Why does A3B need so much memory?

Qwen lists 30.5B total parameters and 3.3B activated. Routing selects experts during inference, but full GPU residency still needs the model’s full weights. Active parameters are not the weight footprint and do not establish measured speed.

Which runtime and file should I use?

LM Studio Community provides a matching Q4_K_M GGUF conversion, about 18.60 GB before cache and buffers. Use a current runtime with this MoE architecture and tool-call format. The original checkpoint is Apache 2.0 and non-thinking-only. The Q5 table is a planning profile; the linked repository has no Q5 file.

Can I load an entire repository?

The publisher lists 262,144 native tokens. Our 4K and 16K estimates do not verify that window. Increase context only after checking available memory, prompt-processing time and whether the model handles your repository’s task correctly.

How are these recommendations chosen?

We compare dedicated GPU memory tiers using the main Finder’s memory calculation at the stated quantisation and context. These tiers describe memory fit, not speed or output quality.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
