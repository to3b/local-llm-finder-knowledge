A coding model to try on 8 GB

Start with Q4_K_M and 4,096 context if you have an 8 GB GPU. The official download is about 4.68 GB. That leaves a useful planning margin, but check the app's memory use and how many layers actually run on the GPU.

The checkpoint here is Qwen/Qwen2.5-Coder-7B-Instruct, with 7.61 billion parameters and an Apache 2.0 licence. The publisher describes training for code generation, reasoning and repair. Judge it on your own language and tests; a coding label does not establish that generated code is correct.

Pick one complete download

The official GGUF directory lists approximately:

  • Q4_K_M: 4.68 GB.
  • Q5_K_M: 5.44 GB, about 0.76 GB more.
  • Q6_K: 6.25 GB.

The directory includes merged files and split versions. Choose one complete version: the merged Q4 file or both numbered Q4 shards. Downloading just the first shard leaves the model incomplete.

File sizes are rounded decimal GB. Using the configuration, our single-conversation FP16 cache estimate is 0.23 GB at 4,096 tokens or 0.47 GB at 8,192. It stores keys and values across 28 layers, four KV heads and 128 values per head at two bytes each. Working buffers are additional; this is not measured VRAM use.

Keep the first coding task small

Use the Instruct checkpoint and its chat template. Start with one function, a clear expected result and tests you can run. Compare Q4 and Q5 on the same task before spending the extra memory. An RTX 4060 is a reasonable place to start this memory check; see Q4 vs Q5.

The base model card advertises up to 131,072 tokens with YaRN, while the GGUF card lists 32,768 and additional limits for extended context. Confirm support in your exact app instead of assuming a 128K download.

Compare the 14B version only after checking whether the larger model improves your tasks enough to justify its memory cost.
