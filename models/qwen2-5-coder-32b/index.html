Setup and common questions

Which Coder version is this?

Use Qwen2.5-Coder-32B-Instruct, not the base checkpoint. Qwen provides GGUF files under Apache 2.0. Keep the Instruct chat template and download all shards for the chosen quantisation.

When should I choose the smaller Coder?

Try the 14B Coder if 32B leaves too little memory or responds too slowly. Model size does not establish which writes better code for your repository. Compare the same task and run the generated code’s tests.

Does 128K context fit this hardware?

The publisher describes 131,072-token support with YaRN; the default configuration is 32,768. Our 4K and 16K calculations do not verify the full window. Longer inputs increase cache memory and prompt-processing work.

How are these recommendations chosen?

We compare dedicated GPU memory tiers using the main Finder’s memory calculation at the stated quantisation and context. These tiers describe memory fit, not speed or output quality.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
