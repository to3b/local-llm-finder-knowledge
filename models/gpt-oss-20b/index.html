Setup and common questions

Which format and runtime do I need?

Use a runtime with explicit gpt-oss, MXFP4 and Harmony support. MXFP4 is not interchangeable with an ordinary GGUF Q4_K_M conversion. Harmony must handle reasoning and final-answer channels; a generic chat template can give misleading output.

How should I choose context and reasoning effort?

The publisher lists up to 131,072 context tokens. Runtime support and memory are separate limits. Start with the context you need, and keep low, medium or high reasoning effort fixed when comparing time to an answer.

Does the active parameter count reduce the memory needed?

The model has about 20.9B total parameters and 3.6B active per token. The active count describes computation, not the amount of weights that must be stored. It does not establish inference speed.

How are these recommendations chosen?

We compare dedicated GPU memory tiers using the main Finder’s memory calculation at the stated quantisation and context. These tiers describe memory fit, not speed or output quality.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
