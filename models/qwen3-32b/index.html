Setup and common questions

Which file should I start with?

Use the publisher’s Qwen3-32B-GGUF files at Q4_K_M. Download every shard belonging to the chosen quantisation. The table uses the Finder’s weight input; compare it with the exact files and your runtime’s reported memory.

Should thinking mode be on?

This checkpoint supports thinking and non-thinking modes. Choose one explicitly and keep it fixed when comparing answers or timings. Thinking consumes output tokens and time before the final answer.

Can I use the advertised long context?

Qwen lists 32,768 native tokens and up to 131,072 with YaRN. Extended context needs runtime support and extra cache memory. The short-context fit here does not verify YaRN or the full window. The model uses Apache 2.0.

How are these recommendations chosen?

We compare dedicated GPU memory tiers using the main Finder’s memory calculation at the stated quantisation and context. These tiers describe memory fit, not speed or output quality.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
