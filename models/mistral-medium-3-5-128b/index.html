Catalogue starting point

This draft covers Mistral Medium 3.5 128B as listed in the Local LLM Finder catalogue. It is a starting point for a sourced reference. The figures below are catalogue planning inputs and still need checking against the exact model checkpoint.

  • Family: Mistral.
  • Total parameter input: 128 billion.
  • Base Q4 weight estimate: 82 GB.
  • Context planning limit: 64K tokens.
  • Cache planning input: 0.36 GB per 1K tokens.

The catalogue entry is the source for this draft's figures. A catalogue context input does not establish the publisher's native context limit or the support available in your local app.

A memory-planning example

Using this entry's inputs, 8K context adds approximately 2.88 GB of cache. Together with the base Q4 estimate, that gives about 84.88 GB before working buffers, runtime overhead and memory used by other applications.

This calculation illustrates the Finder's planning assumptions. It is not a measured memory requirement or the size of an official download. Architectures, cache formats and CPU/GPU offload can change the actual allocation.

See Q4 vs Q5 and context length when choosing the precision and conversation budget.

What to verify before publication

  • Confirm the exact checkpoint, model family and parameter counts with the publisher.
  • Link the official model card and licence.
  • Check available quantized files and their actual sizes.
  • Confirm native and extended context, chat template and runtime support.
  • Record the hardware, runtime version, quantization, context and offload settings for any test results.
  • Add model-specific strengths and limitations supported by evidence.
