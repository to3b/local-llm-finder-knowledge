Setup and common questions

How should I set up a first run?

Use Qwen/Qwen3-14B, the publisher’s GGUF file and the current Qwen3 chat template. Confirm GPU offload and check memory during generation before increasing context. Keep thinking mode fixed between runs.

Can I use longer context?

Qwen lists 32,768 native tokens and up to 131,072 with YaRN. The extended limit needs explicit runtime support and additional cache memory; it is not a promise of GPU fit.

What if it does not fit?

Reduce context, use a smaller file or offload some layers to system RAM. Compare Qwen3 8B if you want to keep the workload on the GPU. See context length.

How are these recommendations chosen?

We use the main Finder’s balanced task selection and memory calculation, limited to models with published guides here. Task scores and speed proxies are planning inputs, not measured quality rankings.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
