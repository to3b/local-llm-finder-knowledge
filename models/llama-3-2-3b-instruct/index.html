Setup and common questions

Which Llama checkpoint is this?

Use Llama-3.2-3B-Instruct, the text-only assistant model. LM Studio Community provides a matching Q4_K_M GGUF conversion. Its file is about 2.02 GB; the Finder uses a conservative 2.70 GB weight input before cache and buffers. Check the chat template.

Why do different downloads list different context limits?

Meta lists 128K for the original text checkpoint and 8K for its separate quantised editions. A converted GGUF is not automatically that official quantised edition. Start at 4K; the listed maximum does not establish a memory fit.

What licence applies?

The Llama 3.2 Community License and Acceptable Use Policy apply. Review Meta’s terms before distributing a model or building a service. This page’s Q4 weight input is a planning estimate, not a verified download size.

How are these recommendations chosen?

We compare dedicated GPU memory tiers using the main Finder’s memory calculation at the stated quantisation and context. These tiers describe memory fit, not speed or output quality.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
