Setup and common questions

Which RTX 2060 is this?

This page covers the original 6 GB RTX 2060. Other 2060 variants have different memory. Match the exact VRAM shown by your hardware; a shared family name is not enough.

What should I change if memory is tight?

Start at 4K context, close other GPU-heavy applications and check the runtime’s reported allocation. Try a smaller model before adding a larger cache. Display use and runtime buffers can take more memory than the planning reserve.

Can CPU offloading make a larger model usable?

It can move some weights into system RAM when the runtime supports it. That is a different setup from this full-GPU table and can slow generation. Use the Finder to compare smaller models, then test your exact configuration rather than treating a successful load as useful speed.

How are these recommendations chosen?

We use the main Finder’s balanced task selection and memory calculation, limited to models with published guides here. Task scores and speed proxies are planning inputs, not measured quality rankings.

Allocations are shown in GiB; weight inputs use decimal GB. Nominal hardware capacities are treated as GiB tiers. We include a 0.9 decimal-GB runtime allowance and a 3% reserve (0.15–1.5 GiB). Cache settings and runtime buffers can change the fit. See the calculation assumptions.
