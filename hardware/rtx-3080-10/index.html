Setup and common questions

Why does the exact RTX 3080 variant matter?

NVIDIA lists 10 GB and 12 GB RTX 3080 variants. This page uses 10 GB. A recommendation calculated for the 12 GB version can exceed this card’s budget; select the exact model in the Finder.

Should I try a 14B model?

At the Q4 and 4K settings shown, the reviewed 14B profiles exceed this full-GPU budget. Start with the listed smaller models. More GPU compute does not make weights and cache fit into less VRAM.

Can I increase Q4 to Q5?

Check the exact model’s Q5 profile in the Finder first, keeping context fixed. It uses more weight memory and reduces headroom. Compare answers on your own task; higher precision does not guarantee a useful improvement, and this page does not establish inference speed.

How are these recommendations chosen?

We use the main Finder’s balanced task selection and memory calculation, limited to models with published guides here. Task scores and speed proxies are planning inputs, not measured quality rankings.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
