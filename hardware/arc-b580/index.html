Setup and common questions

Which Arc card does this cover?

Intel’s desktop Arc B580 has 12 GB GDDR6 and uses Xe2. This page does not cover the B570 or an integrated Arc GPU. Check the exact product and dedicated memory when selecting hardware.

Can I use a CUDA download?

CUDA is NVIDIA’s backend. Choose a build supporting Intel instead. llama.cpp’s SYCL documentation lists Arc B580 among verified devices, but the correct driver and oneAPI/runtime combination still matter. Follow the current backend instructions for your operating system.

Why does the model load but respond slowly?

Check the log for GPU detection and offloaded layers before changing the model. CPU fallback can load the same file with very different performance. This page establishes planning memory fit only; no reviewed B580 speed measurements are available here.

How are these recommendations chosen?

We use the main Finder’s balanced task selection and memory calculation, limited to models with published guides here. Task scores and speed proxies are planning inputs, not measured quality rankings.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
