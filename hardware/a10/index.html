Catalogue starting point

This draft covers NVIDIA A10 with the catalogue's 24 GB memory configuration. Verify the exact desktop, workstation or accelerator variant before relying on these specifications.

  • Vendor: NVIDIA.
  • Architecture: Ampere.
  • Dedicated memory input: 24 GB.
  • Memory bandwidth input: 600 GB/s.
  • Series: Data Center.

The Finder catalogue entry supplies these figures. They are awaiting review against official specifications and are not results from a hardware benchmark.

Planning local model memory

A 24 GB memory configuration is a starting capacity figure. The model's weights, context cache and runtime buffers must share the memory available to the application. Display use and other applications can reduce that budget.

Compare an exact model download with the free memory shown by your runtime. A file that fits on disk does not establish full GPU residency. CPU offload can change the allocation and performance, so record whether it is used.

Use Q4 vs Q5 to assess weight precision and context length to plan cache requirements. Memory capacity and generation speed should be checked separately.

What to verify before publication

  • Confirm the exact board name, memory configuration and official bandwidth specification.
