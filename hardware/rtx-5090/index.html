Setup and common questions

Which RTX 5090 does this cover?

The desktop RTX 5090 has 32 GB GDDR7 and uses Blackwell. This page does not cover the laptop GPU. Compare the dedicated memory on your exact card before following the shortlist.

Why might a model fit but fail to use the GPU?

Use an NVIDIA driver and a runtime build that support Blackwell. Older CUDA builds can lack the required GPU support. Check that the runtime detects your card and reports layers loaded onto it; memory fit alone cannot establish compatibility.

What does 32 GB change?

It leaves more space around the 30–32B Q4 planning profiles than a 24 GB card. Compare Q5 or longer context in the Finder before increasing either. This site has no reviewed RTX 5090 timing measurements to establish how fast those settings run.

How are these recommendations chosen?

We use the main Finder’s balanced task selection and memory calculation, limited to models with published guides here. Task scores and speed proxies are planning inputs, not measured quality rankings.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
