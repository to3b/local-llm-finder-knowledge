Setup and common questions

Which AMD card is this?

The RX 7900 XTX has 24 GB GDDR6. The RX 7900 XT is a different card. These comparisons use dedicated VRAM; they do not add system RAM to the full-GPU budget.

Which backend should I choose?

Use a runtime with an AMD backend, such as llama.cpp HIP or Vulkan. For ROCm, check AMD’s matrix for your exact GPU, operating system and software version. A Linux support entry does not establish the same support on Windows or WSL.

How do I know inference is on the GPU?

Check the runtime log for GPU detection and offloaded layers. A model can load through CPU fallback without using the expected backend. Record that backend when sharing a test; results from a different GPU or software stack do not establish this card’s speed.

How are these recommendations chosen?

We use the main Finder’s balanced task selection and memory calculation, limited to models with published guides here. Task scores and speed proxies are planning inputs, not measured quality rankings.

Allocations are shown in GiB; weight inputs use decimal GB. Nominal hardware capacities are treated as GiB tiers. We include a 0.9 decimal-GB runtime allowance and a 3% reserve (0.15–1.5 GiB). Cache settings and runtime buffers can change the fit. See the calculation assumptions.
