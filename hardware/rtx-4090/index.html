Setup and common questions

Which RTX 4090 does this page cover?

The desktop RTX 4090 has 24 GB GDDR6X. The RTX 4090 Laptop GPU is a separate product. Check the exact manufacturer’s dimensions, connectors and power requirements before installing a card.

What should I check on my first run?

Use a working NVIDIA backend and one model at 4K context. Confirm GPU offload and watch memory during generation. Keep the file, prompt and thinking mode fixed between runs.

Can 24 GB handle maximum context?

Not necessarily. Cache memory grows with context and simultaneous conversations. A model that fits at 4K can exceed this budget at its advertised maximum. See context length and test the settings your workload needs.

How are these recommendations chosen?

We use the main Finder’s balanced task selection and memory calculation, limited to models with published guides here. Task scores and speed proxies are planning inputs, not measured quality rankings.

GPU memory includes weights, context cache and a 0.9 GB runtime allowance, plus a 3% reserve (0.15–1.5 GB). Cache format and runtime buffers can change the fit. See the calculation assumptions.
